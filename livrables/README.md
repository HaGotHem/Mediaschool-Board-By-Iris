# Livrables à compléter par les étudiants

Ces fichiers sont des modèles, pas des preuves déjà produites. Remplacez les mentions « à renseigner » et ajoutez vos sources/export. Toutes les données dans le dépôt restent fictives.

| Production | Destination | Responsable |
|---|---|---|
| Répartition nominative | `REPARTITION.md` | Pilotage, chaque étudiant confirme |
| Hypothèses et décisions | `DECISIONS.md` | Pilotage |
| MCD source + image, MLD | `conception/` | Pôle Merise |
| Dictionnaire et règles | `conception/DICTIONNAIRE.md` | Merise/API |
| Rapport de tests + PV | `tests/RAPPORT.md`, `tests/PV.md` | QA/pilotage |
| Transmission/checklist | `deploiement/` | Infrastructure/intégration |
| Preuve individuelle | `individuel/PRENOM_NOM.md` à créer depuis le modèle | Chaque étudiant |

Le code des migrations et des tests reste avec le code, pas recopié dans un document. Le livrable établit le lien avec le commit testé et explique la décision.
